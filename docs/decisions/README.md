# Decisions

Design questions that came up while building ShotDetector and FrameReader, the choices considered, and what the user
decided: one file per question, named `YYYY-MM-DD-what.md` after the day it was decided, so the folder lists them
oldest first and parallel pull requests never edit the same file. Add one whenever a design question is put to the
user (title, then the question, the choices and the answer, with why).

When a later decision or change reverses or overtakes one, the older file gets a closing line that says so and links
the newer: `Since YYYY-MM-DD ([newer.md](newer.md)) ...`. Each file then reads as current, and the folder stays a record
of what was decided when.
