# GitHub's "Latest" release: always ShotDetector's (2026-10-14)

FrameReader 2.2.1, released alone, became the repository's Latest release, so the front page and the latest-release
link pointed at FrameReader instead of ShotDetector and its CLI binaries. Asked: **always ShotDetector's** (over
whichever is newest). v2.2.0 was marked Latest again by hand, and release.yml creates FrameReader's releases with
`--latest=false`.
